⚡ TROUBLESHOOTING

"Script not found" errors:
  → Make sure bitburner-update.js --all completed successfully
  → Check that folders were created (utils/, modules/, batch/, etc.)
  → Re-run: run bitburner-update.js --all

"Not enough RAM" errors:
  → Auto-manager needs ~8-10GB RAM on home server
  → Solution 1: Upgrade home RAM
  → Solution 2: Use simpler version: run batch/smart-batcher.js

Scripts not doing anything:
  → Check logs: tail utils/auto-manager.js
  → Check status: run utils/auto-manager.js --monitor
  → Verify it's running: ps

Making no money:
  → Wait 5-10 minutes for the prep phase
  → System needs time to:
    • Analyze targets
    • Deploy batch scripts
    • Weaken servers to minimum security
  → Check after prep: income should increase significantly

Need to stop everything:
  → run utils/global-kill.js
